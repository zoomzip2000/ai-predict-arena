# AI Developer Manual — AI Predict Arena (AIPA)

Привет, AI-разработчик! Этот документ описывает правила поведения, стандарты кодирования и архитектуру проекта **AI Predict Arena (AIPA)**. Прочти его перед началом любых изменений в кодовой базе.

---

## 1. Архитектура и Структура проекта

Проект представляет собой Web3-платформу прогнозов новостей с агентным ИИ-движком и Telegram Mini App.

### Компоненты системы:
1. ☕ **`mycoin-server-v2`** (переименовывается в **`aipa-server`**):
   - **Стек**: Java 17, Spring Boot, Spring Data JPA, Spring Security (JWT), Liquibase, WebSockets (STOMP).
   - **База данных**: Supabase (PostgreSQL).
   - **Роль**: Центральный API-сервер, ведение счетов, хранение прогнозов, WebSocket-рассылка событий.
2. 🌐 **`mycoin-webapp-v2`** (переименовывается в **`aipa-webapp`**):
   - **Стек**: Next.js 12, TypeScript, Redux Toolkit, Framer Motion, Lightweight Charts, SockJS.
   - **Роль**: Пользовательский веб-сайт (котировки, графики, прогнозы, лидерборд).
3. 🛡️ **`mycoin-admin-webapp-v2`** (переименовывается в **`aipa-admin`**):
   - **Стек**: React 18, TypeScript, Redux Toolkit, Sass.
   - **Роль**: Панель администратора для настройки платформы и модерации ИИ-судей.
4. 🤖 **`mycoin-tapbot-back`** (переименовывается в **`aipa-tapbot-back`**):
   - **Стек**: Node.js, Express, TypeScript, PG-Client.
   - **Роль**: Бэкенд Telegram-бота и игры, интегрированный с общей базой данных Supabase.
5. 📱 **`mycoin-tapbot-front`** (переименовывается в **`aipa-tapbot-front`**):
   - **Стек**: Vite, React 18, TypeScript, Redux Toolkit, Sass.
   - **Роль**: Игровой интерфейс кликера внутри Telegram.

## 2. Стандарты кодирования (Coding Guidelines)

### Общие правила:
- **Соло-разработка**: Проект пишется для одного автора. Не добавляй ссылки на сторонних разработчиков в коммитах или комментариях к коду.
- **Приватность данных**: Никогда не коммить ключи API (включая Gemini API), пароли к базам данных и адреса серверов. Используй `.env` и `application.properties` с чтением из переменных окружения. Все секретные ключи, логины и пароли для локальной работы агентов хранятся в неотслеживаемом файле [secrets.json](file:///D:/MyCoin/ai-predict-arena/secrets.json) в корне проекта — ты можешь считывать его данные для настройки окружения, но никогда не коммить его!
- **Сохранение комментариев**: Сохраняй все важные существующие комментарии и документацию, если они не противоречат рефакторингу.

### Backend (Java):
- **Стиль**: Spring Boot Best Practices. Используй конструкторы для внедрения зависимостей (`@Autowired` над конструктором).
- **Пакеты**: Основной пакет проекта должен быть изменен на `ai.predict.arena` (вместо старого `ua.herutskyi.mycoin`).
- **Схема БД**: Все изменения структуры PostgreSQL базы данных делаются строго через Liquibase миграции (`src/main/resources/liquibase/`).

### Frontend (Next.js / React):
- **Стиль**: Функциональные компоненты React с хуками.
- **TypeScript**: Обязательная типизация для новых компонентов. Избегай использования типа `any`.
- **Стилизация**: Использование новой дизайн-системы, описанной в [design.md](file:///D:/MyCoin/design.md). Стили пишем в соответствии с правилами глассморфизма.
