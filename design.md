# UI/UX Design System — AI Predict Arena (AIPA)

Этот документ является единым источником правды (**Single Source of Truth**) для дизайн-системы проекта **AI Predict Arena (AIPA)**. Дизайн-система строго основана на реализованном коде в [ui-kit.html](file:///D:/MyCoin/ai-predict-arena/ui-kit.html) (Светлая тема) и [ui-kit-dark.html](file:///D:/MyCoin/ai-predict-arena/ui-kit-dark.html) (Тёмная тема).

---

## ⚠ КРИТИЧЕСКИЕ ПРАВИЛА (Обязательно к исполнению)

> Нарушение данных правил является недопустимым и ломает визуальную целостность платформы.

### 1. Строгое следование стилю и шрифтам
Разработка платформы должна **строго 1 в 1** придерживаться стилей, теней, скруглений, поведения и шрифтов, заданных в [ui-kit.html](file:///D:/MyCoin/ai-predict-arena/ui-kit.html) и [ui-kit-dark.html](file:///D:/MyCoin/ai-predict-arena/ui-kit-dark.html). Никакие отклонения в палитрах или базовой геометрии недопустимы.

### 2. Абсолютный запрет на эмоджи (Emoji)
- **ЗАПРЕЩЕНО** использовать любые эмоджи (😀🎯🔔🏆 и другие) в интерфейсе, кнопках, иконках, модальных окнах, уведомлениях, таблицах или коде компонентов.
- Для любых визуальных обозначений разрешено использовать **только SVG-иконки Phosphor Icons**, входящие в состав UI-Kit.

### 3. Библиотека иконок — Phosphor Icons
- **Библиотека:** [Phosphor Icons Web Components](https://github.com/phosphor-icons/webcomponents) (MIT License).
- **Подключение:** `<script type="module" src="https://unpkg.com/@phosphor-icons/webcomponents@2.1"></script>`
- **Стиль весов (weight):** Использовать веса `light` (по умолчанию) или `regular` для обеспечения гармонии с мягкими тенями нейморфизма.
- **JS-Хелпер:** Для удобства и шаблонизации используется custom element хелпер `PhIcon` (зарегистрированный как `<ph-icon>`), который динамически транслирует переданные атрибуты:
  ```html
  <ph-icon name="chart-line" weight="light" class="icon-sm"></ph-icon>
  ```
- **Запрещённые веса:** `weight="fill"` (слишком тяжелый для нейморфических поверхностей).

## 1. Типографика и модульная сетка (Print-Style Grid)

Дизайн платформы следует строгим правилам разметки и вертикального ритма, аналогичным тем, которые используются в профессиональном книжном и журнальном книгоиздании (типографическая сетка).

### 1.1 Основные шрифты
- **Шрифт интерфейса (UI):** `Space Grotesk` (начертания 300, 400, 500, 600, 700). Строгий, геометрический гротеск с sci-fi глифами. Letter-spacing на body: `-0.01em`, на крупных заголовках: до `-0.03em`.
- **Шрифт данных и чисел:** `Space Mono` (начертания 400, 700). Используется для всех числовых значений: балансы, ставки, коэффициенты, пулы, даты и ID событий. Все числовые таблицы должны использовать `font-variant-numeric: tabular-nums` для фиксированной ширины цифр.
- **Подключение:**
  ```html
  <link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300;400;500;600;700&family=Space+Mono:ital,wght@0,400;0,700;1,400&display=swap" rel="stylesheet" />
  ```

### 1.2 Типографическая сетка по вертикали (Baseline Grid)
- **Базовый шаг сетки (Grid Unit):** **8px**. Все размеры, внутренние отступы (padding), внешние отступы (margin), высоты строк и контейнеров должны быть строго кратны **8px** (или в крайнем случае **4px** для микроэлементов):
  - Микро-расстояния: `4px` / `8px` / `12px`
  - Стандартные отступы: `16px` / `24px` / `32px`
  - Секционные отступы: `48px` / `64px` / `80px`
- **Вертикальный ритм строк (Vertical Rhythm):** Высота строки (`line-height`) каждого элемента текста должна быть согласована с сеткой, чтобы базовые линии шрифта всегда попадали в шаг сетки:
  ```css
  h1 { font-size: 52px; line-height: 1.05; letter-spacing: -0.03em; margin-bottom: 24px; }
  h2 { font-size: 38px; line-height: 1.15; letter-spacing: -0.02em; margin-bottom: 16px; }
  h3 { font-size: 26px; line-height: 1.25; letter-spacing: -0.01em; margin-bottom: 12px; }
  p, body { font-size: 15px; line-height: 1.55; letter-spacing: -0.01em; margin-bottom: 16px; }
  ```

### 1.3 Сетка разметки (Layout Grid)
- **Максимальная ширина контейнера:** `1200px` (центрированный, с горизонтальными отступами безопасности `40px` по бокам).
- **Сетка карточек (Grid System):** Использование CSS Grid с фиксированными зазорами (`gap`):
  - Основные зазоры между карточками: строго `24px`.
  - Зазоры между внутренними блоками: `16px`.

## 2. Цветовая палитра и Тени (Neumorphism Tokens)

Дизайн-токены определяют цвета и параметры теней для обеих тем. Все legacy-переменные старого проекта (такие как `#212745`) полностью удалены.

### 2.1 Тёмная тема (Dark Neumorphism)
Базовый фоновый оттенок — **нейтральный тёмно-серый `#22242a`**. Все тени рассчитываются математически вокруг этого цвета.

```css
:root {
  --nm-bg:          #22242a;   /* Основной фон и поверхности */
  --nm-bg-light:    #1a1c20;   /* Глубокий фон (вдавленные элементы) */
  --nm-bg-white:    #292c34;   /* Светлый фон для ховеров строк */
  --nm-surface:     #22242a;   /* Поверхность карточек */
  --nm-border:      #2c2f37;   /* Цвет тонких рамок */

  /* Текстовые переменные */
  --nm-text-dark:   #f3f4f6;   /* Активный белый (заголовки) */
  --nm-text-body:   #cbd5e1;   /* Светло-серый (основной текст) */
  --nm-text-muted:  #94a3b8;   /* Серый (описания, второстепенный) */
  --nm-text-gray:   #64748b;   /* Placeholder */

  /* Акцентные неоновые цвета */
  --nm-secondary:   #06b6d4;   /*  циановый неон — Основной CTA */
  --nm-success:     #22c55e;   /* Зелёный неон — Рост / Выигрыш */
  --nm-danger:      #ef4444;   /* Красный неон — Падение / Проигрыш */
  --nm-warning:     #eab308;   /* Жёлтый неон — Ожидание */
  --nm-info:        #9333ea;   /* Фиолетовый неон — Вторичный акцент */
  --nm-dark:        #1a1c20;
  --nm-soft:        #22242a;

  /* Нейморфические тени тёмной темы */
  --shadow-soft:      6px 6px 12px #15161a, -6px -6px 12px #2f323c;
  --shadow-soft-sm:   3px 3px 6px #15161a, -3px -3px 6px #2f323c;
```

## 3. Граничные радиусы (Border Radius Grid)

Скругления углов также стандартизированы для поддержания гармонии сетки:
- Базовый малый шаг (`--radius-sm`): `0.3rem` (4.8px) — для мелких чекбоксов, мини-кнопок.
- Базовый средний (`--radius`): `0.55rem` (8.8px) — для кнопок, полей ввода, аватаров.
- Большой радиус (`--radius-lg`): `1rem` (16px) — для стандартных карточек, таблиц, аккордеонов.
- Сверхбольшой радиус (`--radius-xl`): `1.5rem` (24px) — для модальных окон, карточек предсказаний.
- Круговой радиус (`--radius-pill`): `50rem` (круглые кнопки, статусные плашки).

## 4. Спецификация UI-компонентов и классов

В коде запрещено использовать старые классы из MyCoin. Разметка должна строиться строго на основе следующих стандартизированных компонентов:

### 4.1 Кнопки (Buttons)
- **Базовый класс:** `.btn` (устанавливает шрифты, размеры, отступы, убирает стандартные рамки).
- **Выпуклая кнопка (Default):** `.btn.btn-primary`. Имеет тень `var(--shadow-soft)`. При клике (`:active`) или добавлении класса `.active` переходит во вдавленное состояние `var(--shadow-inset)`.
- **Акцентная кнопка (Secondary / CTA):** `.btn.btn-secondary`. Циановый неон в тёмной теме, синий — в светлой.
- **Кнопка успеха:** `.btn.btn-success` (Зелёный).
- **Кнопка ошибки / падения:** `.btn.btn-danger` (Красный).
- **Иконка-кнопка:** `.btn-icon`. Квадратная кнопка `44×44px` для размещения одиночной иконки.

### 4.2 Поля ввода (Inputs)
- **Базовое поле:** `.form-control` (всегда вдавленное состояние `var(--shadow-inset)` с рамкой `var(--nm-border)`). Радиус скругления строго `--radius` (8.8px). При фокусе получает легкую подсветку.
- **Группа ввода:** `.input-group` (объединяет инпут и текстовую плашку `.input-group-text` справа, например, для указания валюты `USDT`).

### 4.3 Карточки (Cards)
- **Обычная карточка:** `.card` (выпуклая тень `var(--shadow-soft)`, при наведении плавно сдвигается вверх на `2px` и тень увеличивается).
- **Вдавленная карточка:** `.card-inset` (вдавленная тень `var(--shadow-inset)` для логически завершенных блоков или второстепенных панелей).
- **Карточка предсказания:** `.pred-card` (закругление `var(--radius-xl)` (24px)). Внутри содержит центрированный блок с суммой ставки `.pred-card__amount` (моноширинный Space Mono, 60px), список параметров `.pred-card__list` и кнопку действия внизу.

### 4.4 Вкладки (Tabs)
- **Вдавленный контейнер (Pill Tabs):** Контейнер `.tabs` (вдавленная подложка) + кнопки вкладок `.tab-btn`. Активная вкладка получает класс `.active` и выпуклую тень `.shadow-soft-sm`.
- **Подчеркнутые вкладки (Underline Tabs):** Контейнер `.tabs-underline` (линия снизу) + `.tab-underline-btn`. Активная вкладка получает класс `.active` и цветную границу снизу.

### 4.5 Таблицы (Tables)
- **Контейнер:** Таблица всегда оборачивается в `.table-wrapper` для скругления углов и тени.
- **Класс таблицы:** `table.nm-table`. Строки таблицы разделены границами `1px solid var(--nm-border)`. 
- **Заголовки (`th`):** Текст 10px, жирный, в верхнем регистре, с увеличенным letter-spacing `0.10em`.
- **Ячейки данных (`td.data`):** Для числовых столбцов (коэффициенты, суммы) применяется моноширинный шрифт Space Mono.

### 4.6 Модальные окна (Modals)
- **Затемнение фона:** `.modal-overlay` (полупрозрачный черный цвет с размытием `backdrop-filter: blur(4px)`).
- **Контейнер окна:** `.modal-box` (выпуклая тень `var(--shadow-soft-lg)`, скругление углов 24px, внутренние отступы `36px`).
- **Кнопка закрытия:** `.modal-close-btn` (крестик в правом верхнем углу, при ховере вдавливается).

### 4.7 Уведомления и алерты (Alerts)
- Используются классы `.alert.alert-soft` (выпуклый) или `.alert.alert-inset` (вдавленный) в комбинации с цветовыми классами статусов: `.alert-success`, `.alert-danger`, `.alert-warning`, `.alert-info`.

### 4.8 Прочие компоненты
- **Progress Bar:** Контейнер `.progress` (вдавленный) + движок `.progress-bar`.
- **Accordion:** Вертикальный блок `.accordion` с элементами `.accordion-item`, плавно раскрывающимися за счет изменения `max-height`.
- **Кастомные переключатели:** `.check-box` (чекбоксы), `.radio-box` (радио-кнопки) и `.toggle` (свичи), работающие поверх скрытых стандартных инпутов браузера.

## 5. CSS Анимации и Скроллбар

- **Скроллбар:** Тонкий `6px` скроллбар, закругленный под пилюлю. Полностью скрывается на мобильных экранах (≤768px).
- **Анимации плавности:** Все переходы (ховеры кнопок, появление вкладок, раскрытие аккордеона) используют `transition: all 0.2s ease` или `0.3s ease` для гладких микро-анимаций.
