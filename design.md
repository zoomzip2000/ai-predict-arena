# UI/UX Design System — AI Predict Arena (AIPA)

Этот документ описывает дизайн-систему проекта **AI Predict Arena (AIPA)**, включая цветовую палитру, шрифты, стили глассморфизма и правила оформления интерфейсов.

---

## 1. Цветовая палитра (Color Palette)

Новая палитра основана на глубоких космических оттенках фиолетового с яркими неоновыми акцентами для разделения логических слоев интерфейса.

| Роль цвета | Переменная (CSS) | Значение (HEX) | Описание |
| :--- | :--- | :--- | :--- |
| **Background (Основной)** | `--bg-primary` | `#080415` | Фоновый цвет страниц (глубокий фиолетовый) |
| **Background (Вторичный)** | `--bg-secondary` | `#0f0a26` | Фон для карточек и блоков нижнего слоя |
| **Glass Card Bg** | `--glass-bg` | `rgba(23, 15, 52, 0.4)` | Полупрозрачный фон для элементов глассморфизма |
| **Primary (Основной бренд)**| `--color-primary` | `#9333ea` | Фиолетовый неон для кнопок, активных элементов и текста |
| **Accent (Акцент)** | `--color-accent` | `#06b6d4` | Циановый неон для подсветки, победных исходов и графиков |
| **Warning (Предупреждение)**| `--color-warning` | `#f59e0b` | Янтарный для ожидающих событий и предупреждений |
| **Danger (Ошибка / Проигрыш)**| `--color-danger` | `#ef4444` | Красный для проигранных прогнозов |
| **Text Primary** | `--text-primary` | `#f3f4f6` | Белый/светло-серый для заголовков |
| **Text Secondary** | `--text-secondary` | `#9ca3af` | Серый для описаний и второстепенного текста |

## 2. Стили Глассморфизма (Glassmorphism Rules)

Основной визуальный стиль платформы — **Glassmorphic Neomorphism** (эффект полупрозрачного матового стекла со свечением).

### Классическая карточка (Glass Card):
```css
.aipa-glass-card {
    background: var(--glass-bg);
    backdrop-filter: blur(16px);
    -webkit-backdrop-filter: blur(16px);
    border: 1px solid rgba(255, 255, 255, 0.08);
    box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
    border-radius: 16px;
    transition: transform 0.3s ease, border-color 0.3s ease, box-shadow 0.3s ease;
}

/* Эффект наведения (Hover) */
.aipa-glass-card:hover {
    transform: translateY(-4px);
    border-color: rgba(6, 182, 212, 0.3); /* Подсветка цианом */
    box-shadow: 0 10px 40px rgba(147, 51, 234, 0.15); /* Свечение фиолетовым */
}
```

### Неоновые свечения (Neon Glows):
Для выделения важных кнопок и статусов используем размытые тени в цвет элемента:
```css
.neon-glow-purple {
    box-shadow: 0 0 15px rgba(147, 51, 234, 0.4);
}
.neon-glow-cyan {
    box-shadow: 0 0 15px rgba(6, 182, 212, 0.4);
}
```

## 3. Типографика и шрифты

- **Основной шрифт**: `Manrope`, альтернатива — `Inter` (sans-serif).
- **Размеры заголовков**:
  - `H1`: 3.5rem (56px) - 4.5rem (72px), Bold/ExtraBold.
  - `H2`: 2.25rem (36px) - 2.5rem (40px), Semibold/Bold.
  - `H3`: 1.5rem (24px) - 1.75rem (28px), Semibold.
  - `Body`: 1rem (16px) - 1.125rem (18px), Regular.

---

## 4. UI-компоненты и состояния

1. **Кнопки (Buttons)**:
   - **Primary**: Градиент от `--color-primary` (#9333ea) до `--color-accent` (#06b6d4). Белый текст, закругленные углы (rounded-full).
   - **Secondary/Glass**: Прозрачный фон с тонкой рамкой 1px, легкое затемнение при наведении.
2. **Формы ввода (Inputs)**:
   - Темный полупрозрачный фон, рамка `rgba(255, 255, 255, 0.1)`. При фокусе рамка светится циановым `--color-accent` (#06b6d4).
3. **Графики (Charts)**:
   - Линии графиков должны использовать градиент от фиолетового к циановому. Сетка графика — полупрозрачный белый/серый цвет.
